# 双休查询 · 网页版（Web 版）v2

小程序被封后，网页版是完整的替代方案：**功能与小程序完全一致，且不受微信审核/封禁约束**。

## 功能清单（与小程序对齐，2026-09-27 v2）

| 模块 | 说明 |
| --- | --- |
| 企业查询 · 名称搜索 | 输入关键词模糊搜索企业，命中唯一/全称时直接展示详情卡 |
| 企业查询 · 标签清单 | 全部 / 双休 / 非严格双休 / 非双休 / 未录入 五个标签，各带实时企业数，点标签出清单（支持 `#enttag=3` 深链接直达） |
| 产品查询 | 浏览器摄像头扫码（不支持时手输）+ 品牌名称模糊查询，展示「条码→品牌→企业→状态」关系链 |
| 企业录入 | 认领企业 + 三选一标记；**服务端级严格校验**：必须企业全称（含「有限公司/集团/事务所」等字样，≥4字），政治性/政权类词（党、民国、政府、国务院等）一律拒绝，国家/地区词仅放行完整企业名 |
| 产品录入 | 条码 + 品牌 + 搜索/新建所属企业，同条码重复提交即更新 |
| 我的认领 | 查看 / 修改 / 删除自己的标记，删除后状态实时重算 |
| 管理 | 密钥保护的恶意词条扫描+删除（含标记数显示）、**数据导出/导入 JSON 备份**、清空演示数据 |

判定规则与小程序完全一致：全为选项1→双休；含选项2且无选项3→非严格双休；含任一选项3→非双休；无人标记→未录入。

## 二、方案①：WorkBuddy 发布（已完成）

当前线上地址：**https://shuangxiu-query.app.workbuddy.host/**

- 数据模式为「本机演示」（每个访客的数据存在各自浏览器里）；
- 后续要更新内容：改完文件后再发布一次即可覆盖线上。

## 三、方案②：GitHub Pages（顺便开源，见《开源指南.md》）

1. 注册 GitHub → 新建仓库（如 `shuangxiu-query`）；
2. 把 `web/` 里的文件全部上传（网页端 Add file → Upload files，或用 Git）；
3. 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)` → Save；
4. 约 1 分钟后得到 `https://你的用户名.github.io/shuangxiu-query/`。

## 四、方案③：Cloudflare Pages

1. 注册 Cloudflare（dash.cloudflare.com，免费）；
2. 左侧 Workers & Pages → Create → Pages → 直接上传（Direct Upload）；
3. 把 `web/` 文件夹拖进去 → Deploy；
4. 得到 `https://xxx.pages.dev` 域名，国内可正常访问。

## 五、方案④：腾讯云 CloudBase（要真实共享数据库选这个）

小程序封禁后原云环境不可用；用**新的腾讯云账号**重新开一个即可，网页代码不用改逻辑：

1. 注册腾讯云（cloud.tencent.com，实名认证）→ 搜「CloudBase 云开发」→ 开通（按量付费，有免费额度，静态托管+数据库日常用量约 ¥19.9/月起）；
2. 控制台创建环境 → 复制环境 ID；
3. 「登录授权」开启**匿名登录**；数据库建 3 个集合：`enterprises`、`marks`、`products`（权限选「所有用户可读，仅创建者可读写」）；
4. 改 `web/js/config.js`：`DATA_SOURCE: 'cloud'`、`CLOUD_ENV: '新环境ID'`；
5. 「静态网站托管」→ 把 `web/` 全部文件上传 → 得到 `https://环境ID.tcloudbaseapp.com`。

## 六、方案⑤：云服务器 + 域名（长期正式运营再考虑）

1. 买轻量应用服务器（腾讯云/阿里云轻量，约 ¥50~100/年 首购价）；
2. 买域名（.com 约 ¥60/年）→ ICP 备案（免费，1~3 周）；
3. 服务器装 Nginx（或用宝塔面板，图形化操作适合新手）；
4. 把 `web/` 文件上传到站点根目录即可——纯静态站，无需数据库/后端。

## 七、数据模式说明（重要）

- **local（默认）**：数据存每个访客的浏览器里。优点零成本零配置；缺点 A 访客录的企业 B 访客看不到。
- **cloud**：连 CloudBase 数据库，所有访客共享同一份数据（这是「员工共建」的正确形态）。

> 被封小程序里的数据如果还没导出、原环境还能登录云开发控制台，赶紧用「导出」功能拿回来（JSON），可通过管理页「导入备份」恢复到新的云端环境。

## 八、管理页使用

1. 改 `js/config.js` 的 `ADMIN_KEY` 为你自己的密钥（cloud 模式必填，local 模式留空=任意密钥可用）；
2. 打开「管理」标签 → 输入密钥 → 按关键词扫描可疑企业词条（结果含标记人数与字段类型）→ 逐条删除（连带清标记/产品）；
3. 「导出备份 JSON」随时把数据拿在自己手里——**建议每周备份一次**。
